    Glossary¶

    The table may be searched by term, English name, or layer.
    "Layer" denotes the place where the term is first systematically defined; it does not mean that the term may be used only there.

    For English abbreviations (ZF, ZFC, IVT, DCT, etc.) see Abbreviations and English Terms.

    Term English Concise Meaning Layer
    proposition proposition A declarative sentence with a definite truth value 1 Logic
    logical connective logical connective Negation, conjunction, disjunction, implication, equivalence 1 Logic
    predicate predicate A statement containing variables that becomes a proposition once the range of the variables is specified 1 Logic
    universal quantifier universal quantifier "for all" \(\forall\) 1 Logic
    existential quantifier existential quantifier "there exists" \(\exists\) 1 Logic
    axiom axiom An assumption taken as the starting point 1 Logic
    definition definition The precise specification of a new object by means of existing concepts 1 Logic
    theorem theorem A proposition derived from axioms, definitions, and previously proved conclusions 1 Logic
    lemma lemma A subsidiary conclusion serving a principal theorem 1 Logic
    counterexample counterexample A concrete instance that makes a universal proposition false 1 Logic
    contrapositive contrapositive \(\neg Q\to\neg P\) is the contrapositive of \(P\to Q\) 1 Logic
    set set A collection of objects 2 Sets
    subset subset \(A\subseteq B\): every element of \(A\) lies in \(B\) 2 Sets
    power set power set The set of all subsets \(\mathcal P(A)\) 2 Sets
    Cartesian product Cartesian product The set of ordered pairs \(A\times B\) 2 Sets
    binary relation binary relation A subset of \(A\times B\) 2 Sets
    equivalence relation equivalence relation A relation that is reflexive, symmetric, and transitive 2 Sets
    equivalence class equivalence class The set of elements equivalent to \(x\), denoted \([x]\) 2 Sets
    partition partition A family of pairwise disjoint subsets whose union is the whole set 2 Sets
    quotient set quotient set The set whose elements are equivalence classes, \(A/{\sim}\) 2 Sets
    order relation order relation A relation that is reflexive, antisymmetric, and transitive 2 Sets
    map / function map / function A rule assigning to each input a unique output 2 Sets
    injective injective Distinct inputs have distinct outputs 2 Sets
    surjective surjective Every element of the codomain has a preimage 2 Sets
    bijective bijective Both injective and surjective 2 Sets
    composition composition \((g\circ f)(x)=g(f(x))\) 2 Sets
    inverse map inverse map The reverse mapping of a bijection 2 Sets
    natural numbers natural numbers \(\mathbb N\), characterized by the Peano axioms 3 Number Systems
    induction principle induction principle A subset containing 0 and closed under the successor operation is the whole set of natural numbers 3 Number Systems
    recursive definition recursive definition Defining a term by means of its predecessors 3 Number Systems
    integers integers The ring \(\mathbb Z\) constructed from pairs of natural numbers modulo equivalence of differences 3 Number Systems
    rational numbers rational numbers The field \(\mathbb Q\) constructed from pairs of integers modulo equivalence of ratios 3 Number Systems
    real numbers real numbers The complete ordered field \(\mathbb R\) constructed by Dedekind cuts or Cauchy sequences 3 Number Systems
    Dedekind cut Dedekind cut The representation of a real number by a downward-closed subset of the rationals with no greatest element 3 Number Systems
    completeness completeness Every non-empty subset bounded above has a supremum; every Cauchy sequence converges 3 Number Systems
    complex numbers complex numbers Pairs of real numbers with a multiplication, \(i^2=-1\) 3 Number Systems
    countable countable Equipotent with \(\mathbb N\) 3 Number Systems
    uncountable uncountable Not equipotent with \(\mathbb N\) 3 Number Systems
    group group Associativity, identity element, inverse elements 4 Algebra
    abelian group abelian group A commutative group 4 Algebra
    ring ring Additive group + associative multiplication + distributivity 4 Algebra
    field field A commutative ring in which every non-zero element has a multiplicative inverse 4 Algebra
    homomorphism homomorphism A mapping that preserves the operations 4 Algebra
    isomorphism isomorphism A bijective homomorphism 4 Algebra
    kernel kernel The set of elements mapped by a homomorphism to the identity element 4 Algebra
    vector space vector space An additive group over a field + scalar multiplication 4 Algebra
    linear independence linear independence Only the trivial linear combination is zero 4 Algebra
    basis basis Linearly independent and spanning 4 Algebra
    dimension dimension The number of vectors in a basis 4 Algebra
    linear map linear map A mapping that preserves addition and scalar multiplication 4 Algebra
    rank rank The dimension of the image of a linear map 4 Algebra
    determinant determinant An alternating multilinear function that detects invertibility 4 Algebra
    eigenvalue eigenvalue \(Av=\lambda v,\ v\ne0\) 4 Algebra
    inner product inner product A positive definite symmetric bilinear form 4 Algebra
    norm norm A length function that induces a distance 5 Spaces
    metric space metric space A set equipped with a distance 5 Spaces
    open set open set Every point contains an open ball 5 Spaces
    closed set closed set Its complement is open 5 Spaces
    limit point limit point Every neighbourhood contains a point of the set distinct from the given point 5 Spaces
    convergence convergence Points sufficiently far along stay close to the limit 5 Spaces
    Cauchy sequence Cauchy sequence Terms sufficiently far along are arbitrarily close to one another 5 Spaces
    complete complete Every Cauchy sequence converges 5 Spaces
    compact compact Every open cover has a finite subcover 5 Spaces
    connected connected It cannot be split into two non-empty disjoint open sets 5 Spaces
    continuous continuous Preimages of open sets are open; the \(\varepsilon\)-\(\delta\) definition 5 Spaces
    topological space topological space A set together with a specified structure of open sets 5 Spaces
    uniform convergence uniform convergence The supremum of the error tends to 0 6 Analysis
    measure measure A function assigning a "size" to sets 7 Advanced
    Lebesgue integral Lebesgue integral An integral based on measure 7 Advanced
    random variable random variable A measurable function from a sample space to the real numbers 6 Probability
    expectation expectation The weighted average of a random variable 6 Probability
