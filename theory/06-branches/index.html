    核心分支¶

    出处：分析/代数/数论/几何/拓扑/组合/概率的标准教材与 Wikipedia 条目。

    前置：逻辑、集合、数系、代数、空间中的相应部分。分支之间可以并行，但每条分支只使用自己列出的前置。

    这一页不是“学完一个再学下一个”的队列，而是“在共同语言上选择入口”的地图。

    分支总表¶

    分支 建议内部顺序 必要基础 不要求的
    分析学 数项级数 → 单变量微分与积分 → 函数列与一致收敛 → 多变量微积分 实数、度量空间；多变量用线性代数 不需要先学抽象代数
    代数学 群论 → 商群；环论 → 理想与商环；域论 → 域扩张 基本代数结构、等价关系、映射 不需要先学分析
    数论 整除与同余 → 算术函数 → 更深入的整数问题 自然数、整数、归纳法；部分用群环 初等部分不需要分析
    几何学 欧氏几何公理与证明 → 解析几何 → 曲线与曲面 基础逻辑；解析几何用线性代数；曲线曲面用微积分 不需要先学拓扑
    拓扑学 一般拓扑 → 乘积与商空间 → 更深拓扑性质 集合、映射、基础空间概念 不需要先学代数拓扑
    组合数学 计数原理 → 组合恒等式 → 递推与图论 自然数、集合、映射、归纳法 不需要分析
    概率论 有限概率空间 → 条件概率与独立性 → 离散随机变量 集合、计数、实数；无限离散用级数 公理化概率论留到深入

    分析学¶

    入口：实数完备性 + 度量空间 + 连续。

    1. 数项级数：部分和、收敛判别、绝对收敛、幂级数；
    2. 单变量微分：导数、中值定理、Taylor 展开、极值；
    3. 单变量积分：Riemann 积分、微积分基本定理、换元与分部；
    4. 函数列与一致收敛：逐点 vs 一致、极限交换、Weierstrass 判别；
    5. 多变量微积分：偏导、全微分、重积分、曲线/曲面积分、Stokes 型定理。

    边界：Riemann 积分之后才进入测度与 Lebesgue 积分（深入）；不要在只学过 Riemann 积分时把“可积”当成测度论结论。

    代数学¶

    入口：群、环、域的基础定义 + 同态。

    1. 群论：子群、陪集、正规子群、商群、同态基本定理、群作用；
    2. 环论：理想、商环、整环、唯一分解整环、多项式环；
    3. 域论：域扩张、代数扩张、分裂域、Galois 理论（进阶）。

    边界：线性代数不等于抽象代数；矩阵计算可以在代数完成，群环域的结构理论在这里展开。

    数论¶

    入口：整除、欧几里得算法、算术基本定理。

    1. 初等数论：同余、线性同余、CRT、费马/欧拉定理、原根；
    2. 算术函数：\(\varphi,\mu,\tau,\sigma\) 与 Dirichlet 卷积；
    3. 深入：二次剩余、二次互反、丢番图方程、解析/代数数论（深入）。

    边界：初等数论可以在中学竞赛阶段开始；解析数论需要复分析。

    几何学¶

    入口：欧氏几何公理与证明；解析几何用线性代数。

    1. 欧氏几何：公理、全等、相似、圆、尺规作图；
    2. 解析几何：坐标、直线/圆、圆锥曲线、向量方法；
    3. 曲线与曲面：参数化、曲率、第一/第二基本形式（微积分）。

    边界：微分几何需要多变量微积分与线性代数；代数拓扑需要拓扑与群论。

    拓扑学¶

    入口：集合、映射、度量空间中的开集与连续。

    1. 一般拓扑：拓扑空间、基、子空间、连续、紧致、连通、分离公理；
    2. 乘积与商空间：乘积拓扑、商拓扑、粘贴空间；
    3. 更深：紧化、度量化、基本群（代数拓扑，深入）。

    组合数学¶

    入口：自然数、集合、映射、归纳法。

    1. 计数原理：加法/乘法原理、排列组合、二项式定理；
    2. 组合恒等式：双计数、生成函数、容斥；
    3. 递推与图论：递推关系、生成函数、图的基本概念、树、匹配。

    概率论¶

    入口：集合、计数、实数；无限离散用级数。

    1. 有限概率空间：样本空间、事件、概率公理（有限版）；
    2. 条件概率与独立性：Bayes、全概率、独立重复试验；
    3. 离散随机变量：分布、期望、方差、常见分布；
    4. 极限定理：大数律、中心极限定理（需要分析/测度基础）。

    边界：公理化概率论（测度空间上的概率）在深入；不要在分支用“几乎必然”等未定义概念。

    核心定理速查¶

    分支 代表定理 需要的前置
    分析 介值定理、极值定理、中值定理、微积分基本定理 实数完备性、连续、紧致
    分析 一致收敛的极限交换、Weierstrass 判别 函数列、上确界
    代数 Lagrange 定理、群同态基本定理 群、陪集、正规子群
    代数 Cayley–Hamilton 定理 矩阵、特征多项式
    数论 费马小定理、欧拉定理、中国剩余定理 同余、\(\varphi\) 函数
    数论 二次互反律 二次剩余、Legendre 符号
    几何 勾股定理、相似三角形性质 欧氏公理、全等/相似
    拓扑 Tychonoff 定理（乘积紧致） 紧致、乘积拓扑、AC
    拓扑 Urysohn 引理、Brouwer 不动点定理 正规空间、代数拓扑
    组合 抽屉原理、容斥原理、Ramsey 定理 计数、图论
    概率 大数律、中心极限定理 随机变量、期望、特征函数

    这些定理的证明分散在相应分支；本页只给出“名称—前置—位置”。除已在证明页完整证明的条目外，其余均暂缓证明，不要在没有前置的页里直接引用。

    选择顺序的建议¶

    • 想补严格分析：数系实数 → 空间度量空间 → 分析分支；
    • 想补代数：集合等价关系 → 代数群环域 → 代数分支；
    • 想补几何/拓扑：代数线性代数 → 空间空间 → 几何/拓扑；
    • 想补数论/组合：数系自然数/归纳 → 数论或组合；
    • 想补概率：集合/计数 + 实数 → 概率；连续情形再补积分。
