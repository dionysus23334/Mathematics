    初等数学 · 基础启蒙¶

    目标：理解数、运算、测量与基本图形，能够解释计算的含义，并解决简单实际问题。

    这一阶段不要求先学集合论、公理和数系构造；重点是从具体经验建立数量与空间观念。

    模块总表¶

    顺序 模块 主要内容与内部顺序
    1 数量与自然数 分类与对应 → 数数 → 零与自然数 → 数的大小 → 位值与十进制
    2 加减法 合并与增加 → 减少与比较 → 加减互逆 → 计算与估算
    3 乘除法 等量分组 → 乘法 → 平均分与包含除 → 乘除互逆 → 余数
    4 运算规律 交换律、结合律、分配律 → 括号 → 四则混合运算
    5 度量与基本图形 长度、时间、质量等单位 → 线段与角 → 常见平面图形与立体图形
    6 因数与倍数 整除 → 因数与倍数 → 奇偶数、质数与合数 → 公因数与公倍数
    7 分数与小数 单位整体与等分 → 分数大小与等值 → 分数运算 → 小数与分数互化
    8 比、比率与百分数 倍数关系 → 比与单位量 → 百分数 → 折扣、增长和简单比例问题
    9 周长、面积与体积 单位长度、单位面积、单位体积 → 测量 → 常见图形的计算
    10 初步代数与数据 未知数与简单等式 → 简单方程；数据分类 → 统计图 → 平均数

    这些模块不必完全串行。学习加减法时可以结合长度测量；学习乘法时可以用方格理解面积。

    每个模块“要讲清楚什么”¶

    1. 数量与自然数¶

    • 数数不是背口诀，而是一一对应；
    • 零表示“没有”，也是数；
    • 位值制：同一个数字在不同位置表示不同大小；
    • 比较大小：先比位数，再比高位。

    2. 加减法¶

    • 加法：合并、增加、继续数；
    • 减法：拿走、比较、已知和与一部分求另一部分；
    • 加减互逆：\(a+b=c\iff c-b=a\)；
    • 估算：先判断数量级，再决定是否需要精确计算。

    3. 乘除法¶

    • 乘法：相同加数的简便写法；
    • 除法：平均分与包含除是两种模型；
    • 余数：\(a=bq+r,\ 0\le r<b\)；
    • 乘除互逆，但除以零没有意义。

    4. 运算规律¶

    [ a+b=b+a,\qquad ab=ba, ] [ (a+b)+c=a+(b+c),\qquad (ab)c=a(bc), ] [ a(b+c)=ab+ac. ]

    括号改变运算顺序；四则混合运算按“先乘除、后加减、括号优先”。

    5. 度量与基本图形¶

    • 单位换算：长度、面积、体积的单位不同，进率也不同；
    • 线段、射线、直线；
    • 角：锐角、直角、钝角、平角、周角；
    • 平面图形：三角形、四边形、圆；
    • 立体图形：长方体、正方体、圆柱、圆锥、球。

    6. 因数与倍数¶

    • 整除：\(a\mid b\) 表示存在整数 \(k\) 使 \(b=ak\)；
    • 因数与倍数成对出现；
    • 质数是大于 1 且只有 1 和自身两个正因数的自然数；
    • 公因数、最大公因数、公倍数、最小公倍数。

    7. 分数与小数¶

    • 分数是“把单位整体等分后取若干份”；
    • 等值分数：\(\frac12=\frac24\)；
    • 分数加减需要通分，乘法是“分子乘分子、分母乘分母”，除法是“乘倒数”；
    • 小数是十进分数；有限小数与无限循环小数可以化成分数。

    为什么除以分数等于乘倒数？ 因为 \(\frac{a}{b}\div\frac{c}{d}\) 表示“\(\frac{a}{b}\) 里有多少个 \(\frac{c}{d}\)”，即

    \[ \frac{a}{b}\div\frac{c}{d}=\frac{a}{b}\cdot\frac{d}{c}. \]

    8. 比、比率与百分数¶

    • 比 \(a:b\) 表示两个量的倍数关系；
    • 比的前项/后项同乘或同除非零数，比值不变；
    • 百分数是分母为 100 的比；
    • 折扣、增长率、利率都是百分数应用。

    9. 周长、面积与体积¶

    • 周长是边界长度；面积是平面图形所占单位方格数；体积是立体图形所占单位立方体数；
    • 长方形面积 \(S=ab\)，平行四边形 \(S=ah\)，三角形 \(S=\frac12 ah\)，圆 \(S=\pi r^2\)；
    • 面积公式应从拼接、分割或单位方格推导，而不是只背公式。

    10. 初步代数与数据¶

    • 用字母表示未知数或变化的量；
    • 简单方程：\(x+3=8\)，两边同时减去 3；
    • 数据分类、频数、条形图/折线图/扇形图；
    • 平均数 = 总和 ÷ 个数，容易受极端值影响。

    教学原则¶

    1. 先具体，再符号：用实物、图形、数轴解释运算；
    2. 先意义，再算法：先说明“为什么这样算”，再练速度；
    3. 允许非正式语言：先让学生用自己的话解释，再逐步引入标准术语；
    4. 不提前塞公理：这一阶段不要求集合论、Peano 公理或实数构造。

    检查点¶

    • 能解释分数除法为什么乘倒数，而不是只背规则。
    • 能用单位方格解释面积公式。
    • 能判断一个数是否为质数，并求最大公因数/最小公倍数。
    • 能读懂简单统计图，并说明平均数可能误导的情形。
