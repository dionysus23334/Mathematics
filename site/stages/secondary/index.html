    中等数学 · 中学阶段¶

    从算术走向代数、函数与推理。内部区分“基础阶段”和“深化阶段”，对应从初中知识到高中知识的自然过渡，但不绑定某一地区的具体年级。

    数学竞赛是独立拓展模块，见 数学竞赛。

    模块总表¶

    阶段 学习模块 主要内容与内部顺序
    基础 有理数与实数 负数 → 数轴 → 绝对值 → 有理数运算 → 平方根与无理数 → 实数
    基础 代数式 字母表示数 → 整式运算 → 乘法公式 → 因式分解 → 分式及其条件
    基础 方程与不等式 一元一次方程 → 方程组 → 一元一次不等式 → 一元二次方程
    基础 坐标与函数入门 平面直角坐标系 → 变量关系 → 函数与图像 → 一次函数 → 反比例函数 → 二次函数
    基础 平面几何与证明 基本图形关系 → 命题与证明 → 三角形全等 → 四边形 → 相似 → 勾股定理 → 圆
    基础 数据与随机性 数据分布 → 集中与离散程度 → 抽样意识 → 简单随机事件与概率
    深化 集合与逻辑语言 集合与区间 → 条件与结论 → 充分必要条件 → 全称与存在陈述
    深化 函数的系统研究 定义域与值域 → 单调性、奇偶性 → 复合与反函数初步 → 指数与对数函数
    深化 三角函数 相似与直角三角形中的三角比 → 弧度与单位圆 → 三角函数 → 恒等变换与解三角形
    深化 向量与几何 向量运算与坐标 → 数量积 → 直线与圆的方程 → 圆锥曲线；空间位置与立体几何
    深化 数列与离散方法 数列 → 等差与等比数列 → 求和 → 数学归纳法；计数原理 → 排列组合
    深化 概率与统计进阶 条件概率与独立性 → 离散随机变量 → 期望与方差 → 常见离散分布及统计应用
    衔接 变化率与极限直觉 平均变化率 → 割线与切线 → 无限逼近 → 导数初步与面积累积直觉

    “实数”在这里主要通过数轴、根式和运算性质理解，不必先完成 Dedekind 分割；“集合”先作为表达对象范围的语言，不立即展开公理化集合论。

    基础阶段¶

    有理数与实数¶

    • 负数是相反意义的量；数轴把数与位置对应；
    • 绝对值是到原点的距离；
    • 有理数可写成 \(\frac pq\)（\(p,q\in\mathbb Z,\ q\ne0\)）；
    • \(\sqrt2\) 不是有理数（反证法：假设 \(\sqrt2=p/q\) 且互素，推出矛盾）；
    • 实数 = 有理数 + 无理数；实数与数轴一一对应（直觉版）。

    代数式¶

    • 字母表示数，整式运算遵循交换、结合、分配律；
    • 乘法公式： [ (a+b)^2=a^2+2ab+b^2,\quad (a-b)^2=a^2-2ab+b^2, ] [ a^2-b^2=(a+b)(a-b); ]
    • 因式分解是乘法公式的逆用；
    • 分式有意义的条件：分母不为零。

    方程与不等式¶

    • 一元一次方程：移项、合并、系数化一；
    • 方程组：代入消元、加减消元；
    • 一元一次不等式：两边乘/除负数要变号；
    • 一元二次方程：因式分解、配方、求根公式 [ x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}. ]

    判别式 \(\Delta=b^2-4ac\) 决定实根个数。

    坐标与函数入门¶

    • 平面直角坐标系：有序对 \((x,y)\)；
    • 函数：每个自变量 \(x\) 对应唯一 \(y\)；
    • 一次函数 \(y=kx+b\)：图像是直线，\(k\) 是斜率；
    • 反比例函数 \(y=k/x\)：图像是双曲线；
    • 二次函数 \(y=ax^2+bx+c\)：图像是抛物线，顶点与对称轴。

    平面几何与证明¶

    • 命题、条件、结论；
    • 全等三角形：SSS、SAS、ASA、AAS、HL；
    • 相似三角形：AA、SAS、SSS；
    • 勾股定理：直角三角形 \(a^2+b^2=c^2\)；
    • 圆：圆心角、圆周角、切线、弦。

    证明训练从这里开始：每一步都要有依据（定义、公理、已证定理），不能只画图看起来成立。

    数据与随机性¶

    • 平均数、中位数、众数；
    • 方差/标准差衡量离散程度；
    • 抽样要有代表性；
    • 简单概率：有利结果数 / 总结果数（等可能情形）。

    深化阶段¶

    集合与逻辑语言¶

    • 集合、区间、并/交/补；
    • 充分条件、必要条件、充要条件；
    • 全称量词与存在量词；
    • 命题的否定。

    函数的系统研究¶

    • 定义域、值域；
    • 单调性、奇偶性、周期性；
    • 复合函数与反函数；
    • 指数函数、对数函数及其互逆关系。

    三角函数¶

    • 直角三角形中的正弦、余弦、正切；
    • 弧度制与单位圆；
    • \(\sin^2 x+\cos^2 x=1\)；
    • 和角公式、二倍角公式；
    • 正弦定理、余弦定理解三角形。

    向量与几何¶

    • 向量加法、数乘、坐标表示；
    • 数量积 \(\mathbf a\cdot\mathbf b=|\mathbf a||\mathbf b|\cos\theta\)；
    • 直线与圆的方程；
    • 圆锥曲线：椭圆、双曲线、抛物线；
    • 空间向量与立体几何。

    数列与离散方法¶

    • 等差数列、等比数列；
    • 求和公式；
    • 数学归纳法；
    • 计数原理、排列组合。

    概率与统计进阶¶

    • 条件概率 \(P(A\mid B)=P(A\cap B)/P(B)\)；
    • 独立性 \(P(A\cap B)=P(A)P(B)\)；
    • 离散随机变量、期望、方差；
    • 二项分布、几何分布等。

    大学衔接¶

    • 平均变化率 \(\frac{f(x+h)-f(x)}h\)；
    • 割线斜率 → 切线斜率；
    • 无限逼近的直觉；
    • 面积累积与定积分直觉。

    这一阶段只建立直觉，不替代大学的 \(\varepsilon\)-\(\delta\) 定义与严格证明。

    检查点¶

    • 能用反证法证明 \(\sqrt2\) 是无理数。
    • 能判断充分/必要条件，并写出否定。
    • 能完成一个几何证明，每一步给出依据。
    • 能叙述导数与定积分的直观含义，而不只记公式。
