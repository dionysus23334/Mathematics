# 分析学 · Rudin 路线

> 这一支线按 Rudin《数学分析原理》的问题顺序展开，但不照搬教材目录。
>
> 目标：把第 5 层的“度量空间与连续”推进到**证明驱动**的实分析；每一章只使用前面已经建立的结论。

## 与理论体系的关系

| 本支线 | 对应理论层 | 说明 |
|---|---|---|
| 第 1 章 实数系与复数系 | 第 3 层 | 补齐有序域、上确界、Archimedean、n 次根、复数、欧氏空间 |
| 第 2 章 基础拓扑 | 第 5 层 | 度量空间、开闭集、紧致、连通、Cantor 集 |
| 第 3 章 数列与级数 | 第 5–6 层 | 收敛、Cauchy、limsup/liminf、级数判别、幂级数 |
| 第 4 章 连续性 | 第 5–6 层 | 极限、连续、紧致/连通上的性质、间断、单调函数 |
| 第 5 章 微分法 | 第 6 层分析 | 导数、中值定理、Taylor、L'Hôpital |
| 第 6 章 Riemann–Stieltjes 积分 | 第 6 层分析 | 积分存在性、性质、分部积分、换元、可求长曲线 |
| 第 7 章 函数序列与函数项级数 | 第 6 层分析 | 一致收敛、极限交换、等度连续、Stone–Weierstrass |

| 第 9 章 多元函数 | 第 5–7 层 | 线性变换、导数、压缩映射、反函数/隐函数定理 |
| 第 10 章 微分形式的积分 | 第 7 层 | 微分形式、单纯形、Stokes 定理 |
| 第 11 章 Lebesgue 理论 | 第 7 层 | 测度、可测函数、积分、与 Riemann 积分比较、L² |

## 阅读顺序

1. 先读本站第 1–3 层：逻辑、集合、数系；
2. 再读本支线第 1 章：把实数系与复数系补齐；
3. 然后第 2–4 章：拓扑、数列、连续；
4. 第 5–6 章：微分与积分；
5. 第 7–9 章：函数列、特殊函数、多元；
6. 第 10–11 章：微分形式与 Lebesgue。
