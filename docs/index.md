## 两套体系的关系

| 问题 | 走哪套体系 |
|---|---|
| 我想按主题系统学数学 | 常规体系 |
| 我想按分析教材逐章学 | Rudin 体系 |
| 我想按年级/阶段学习 | 教育阶段体系 |
| 我是初学者，不想先学公理化集合论 | 教育阶段的初等数学 |
| 我要补严格证明、分析或代数基础 | 常规体系的逻辑、集合与数系 |
| 我要准备数学竞赛 | 中等数学 → 数学竞赛（几何/代数/数论/组合） |

两套体系**共享同一批概念**，只是组织方式不同。常规体系按主题回答“需要哪些前置”；Rudin 体系按章节回答“分析怎样逐章推进”。教育阶段体系是另一条按学习阶段组织的路线。

## 阅读规则

1. **首次出现的概念必须定义**，或链接到已经完成的前置页。
2. **证明中使用但尚未建立的结论**，必须调整顺序、补证明，或明确标注“暂缓证明”。
3. **等价关系在商集之前**，映射在同构之前，序关系在上确界之前。
4. 理论页回答“依赖什么”；阶段页回答“怎么学、为什么这样排”。
5. 这里给的是**知识地图与学习顺序**，不是完整教材；每一页都可以继续补定义、定理与习题。
