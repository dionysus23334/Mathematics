# 数学竞赛 · 专题拓展

> 定位：中等数学中的独立拓展模块，与基础阶段、深化阶段并列。  
> 目标：深化问题分析与证明能力；具备相应前置后即可进入，不必学完全部中等数学。

## 四个专题

| 专题 | 入门内容 | 核心内容 | 进阶内容 |
|---|---|---|---|
| **几何** | 角度追踪、全等与相似、面积关系、圆的基本性质 | 共线与共点、圆幂与根轴、梅涅劳斯定理与塞瓦定理、位似与旋转 | 螺旋相似、反演、三角形特殊点与综合构型 |
| **代数** | 因式分解、恒等变形、配方、韦达定理、基本不等式 | 多项式、对称式、不等式证明、数列与递推、函数方程 | 多项式插值、根的分析、复杂函数方程、参数与最值综合问题 |
| **数论** | 整除、素数、最大公因数、欧几里得算法、算术基本定理 | 同余、线性丢番图方程、模运算、费马小定理、欧拉定理、中国剩余定理 | 阶与原根、指数赋值、二次剩余、不定方程与无限递降 |
| **组合** | 加法与乘法原理、排列组合、分类枚举、抽屉原理 | 双计数、容斥原理、递推、不变量与单调量、极端原理、图论基础 | 构造与存在性、染色与覆盖、组合恒等式、生成函数、综合图论问题 |

这些是建议的学习层次，不直接对应某项竞赛的官方考纲。具体专题应注明前置条件，例如学习生成函数之前，应先具备多项式和相应的形式运算基础。

## 共用方法基础

四个专题之前，先建立一个共用的“竞赛方法基础”单元：

- 直接证明、反证法、数学归纳法；
- 分类讨论；
- 构造反例；
- 从小规模例子提出猜想；
- 把文字条件翻译成代数/几何/计数语言。

无限递降、极端原理等方法在相应专题中结合问题展开，避免一开始堆积抽象技巧。

## 页面结构

每个专题页统一按以下顺序编排：

1. **前置知识**：进入该专题前应会什么；
2. **核心结论及证明**：定理、引理、常用模型；
3. **方法例题**：按方法归类，不只按题型；
4. **分层练习**：基础巩固 / 专题提升 / 综合挑战；
5. **提示与解答**：先提示，再展开完整证明；
6. **方法总结**：什么时候用、为什么用、失效条件。

## 前置与衔接

- 学完相似三角形 → 可进入竞赛几何入门；
- 学完整除与因数 → 可进入竞赛数论；
- 学完因式分解、韦达定理 → 可进入竞赛代数；
- 学完加法/乘法原理、排列组合 → 可进入竞赛组合。

竞赛不是“超纲技巧集合”；它训练的是**把已有知识组织成证明**的能力。
