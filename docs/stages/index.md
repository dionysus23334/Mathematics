# 教育阶段体系 · 总览

> 按“学习者怎样逐步理解数学”组织：从具体数量、图形和实际问题出发，逐渐进入符号、函数、变化与抽象结构。
>
> 它和理论体系不是互相替代，而是同一个知识库的两种读法。

## 三个主入口

| 入口 | 副标题 | 目标 | 典型起点 |
|---|---|---|---|
| 初等数学 | 基础启蒙 | 理解数、运算、测量与基本图形，能解释“为什么这样算” | 数量、数数、加减 |
| 中等数学 | 中学阶段 | 从算术走向代数、函数、几何证明与随机性 | 有理数、代数式、方程 |
| 高等数学 | 大学及进阶 | 大学公共基础 → 专业核心 → 进阶专题 | 微积分、线性代数、离散数学 |

“初等/中等/高等”在这里是**学习阶段**，不是对数学价值的排序；传统“初等数学”也包含大量中学内容，因此页面同时标注“基础启蒙/中学阶段/大学及进阶”。

## 中等数学的四个模块

| 模块 | 主要内容 | 定位 |
|---|---|---|
| 基础阶段 | 实数、代数式、方程与不等式、函数入门、平面几何、概率统计基础 | 建立中学数学基础 |
| 深化阶段 | 函数、三角、向量、解析几何、数列、概率统计进阶 | 系统拓展知识 |
| **数学竞赛** | **几何、代数、数论、组合** | 专题探索、解题方法与证明训练 |
| 大学衔接 | 极限直觉、变化率、导数初步、面积累积 | 为大学数学做准备 |

竞赛模块有独立入口，但**共享同一套前置规则**：学完相似三角形即可进入竞赛几何入门；学完整除与因数即可进入竞赛数论。

## 与理论体系的对应

| 教育阶段 | 对应的理论层 | 说明 |
|---|---|---|
| 初等数学 | 第 3 层的“自然数、整数、有理数”直观部分 | 先使用数，不先构造数 |
| 中等数学基础 | 第 3 层的数系；第 2 层的集合语言初步 | 实数先通过数轴与运算理解 |
| 中等数学深化 | 第 1 层的证明；第 2 层的映射；第 4 层的向量 | 证明训练逐步出现 |
| 数学竞赛 | 第 1 层方法 + 数论/组合/几何/代数专题 | 不要求学完所有中学内容 |
| 高等数学公共基础 | 第 4–5 层的计算与应用 | 可以与理论路线并行 |
| 高等数学专业核心 | 第 5–6 层的严格理论 | 数学分析、抽象代数、拓扑 |
| 进阶专题 | 第 7 层 | 按专题列前置 |

## 一条推荐主线

> 数量与运算 → 符号与关系 → 函数与空间 → 变化与随机性 → 抽象结构与严格理论。

这条主线不是强制队列。大学公共基础（微积分、线性代数、概率）可以并行；数学专业学习者可以直接选择严格分析路线，不必先完成一遍计算型微积分。

## 页面结构

每个阶段页统一回答：

1. **这一阶段的目标**；
2. **模块顺序与内部顺序**；
3. **每个模块“应当讲清楚什么”**；
4. **与下一阶段的衔接**；
5. **检查点**：能解释、能计算、能证明什么。
