## Relation Between the Two Systems

| Question | Which System to Follow |
|---|---|
| I want to study mathematics systematically by topic | Classical Academic System → Regular System |
| I want to study chapter by chapter following an analysis textbook | Classical Academic System → Rudin System |
| I want to study by year or stage | Educational Stage System |
| I am a beginner and do not want to begin with axiomatic set theory | Elementary Mathematics within the Educational Stage System |
| I need to fill gaps in rigorous proof, analysis, or algebra | Logic, Sets, and Number Systems within the Classical Academic System |
| I am preparing for mathematical competitions | Secondary Mathematics → Mathematical Competitions (geometry/algebra/number theory/combinatorics) |

Within the Classical Academic System there are the Regular System and the Rudin System; the Educational Stage System is organised by learning stage. All three share the same body of concepts; only the entry points differ.

## Reading Rules

1. **A concept must be defined when it first appears**, or linked to a prerequisite page that has already been completed.
2. **Any result used in a proof but not yet established** must be reordered, supplied with a proof, or explicitly marked "proof deferred".
3. **Equivalence relations before quotient sets**, mappings before isomorphisms, order relations before suprema.
4. Theory pages answer "what does this depend on"; stage pages answer "how to study, and why the material is ordered this way".
5. What is offered here is a **knowledge map and a study order**, not a complete textbook; every page can be extended with further definitions, theorems, and exercises.
