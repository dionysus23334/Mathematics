# Abbreviations and English Terms

> English abbreviations occurring in the mathematical literature, arranged by "abbreviation—full name—meaning—first appearance level".  
> The same abbreviation may carry different meanings in other fields; only the uses occurring on this site are listed here.

## Usage Conventions

- At first occurrence write "full name (abbreviation)"; afterwards the abbreviation alone may be used;
- Do not repeat the explanation within the same page;
- If an abbreviation is ambiguous (for example \(L^p\) and \(L_p\)), state this explicitly on the page;
- The Glossary ([Glossary](glossary.md)) collects "concepts", whereas this page collects "abbreviations and English notation".
