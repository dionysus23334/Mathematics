## Do not translate

- LaTeX formulas and symbols;
- code blocks, pseudocode, URLs, file paths, HTML class names, `{#anchors}`;
- table pipe structure and Markdown syntax;
- labels such as `ROUTE A`, `ROUTE B` unless the source has Chinese prose around them.

## Links

Keep all `.md` links and anchors unchanged (the i18n plugin resolves the English suffix). Translate only link labels.

## Headings

Translate heading text but keep explicit anchors exactly, e.g.:

`## 2.1 度量空间 {#r2-1}` → `## 2.1 Metric Spaces {#r2-1}`

## Tone

Formal, precise, textbook-like. Prefer "we show", "it follows", "suppose", "let". Avoid colloquial phrasing. Keep the Chinese term in parentheses only when it disambiguates a technical term on first use; otherwise English only.
